# go/ — 极简 LLM Agent(99 行,纯标准库)

参考 \`agent_100_line/agent.py\` 的思路,用 Go **标准库**实现一个带工具调用的 LLM
Agent,核心逻辑 **99 行**,行为与 [python/](../python/) 版逐条等价。

## 快速开始

\`\`\`bash
export LLM_API_KEY=sk-...

go run .                      # 交互模式
go run . "看看当前目录有什么"   # 一次性执行后退出
\`\`\`

交互模式下输入 \`exit\` / \`quit\`、Ctrl-C 或 Ctrl-D 退出。

## 依赖:没有

Go 标准库自带 \`net/http\` 与 \`encoding/json\`,还自带 \`os/exec\`、\`bufio\`、
\`cmp.Or\`(Go 1.22+)与内置 \`min\`/\`max\`,写这个 agent **一个第三方库都不需要**。
所以 [go.mod](go.mod) 里没有任何 \`require\`,\`go list -deps\` 只显示标准库。

## ⚠️ 关于代码风格:本文件不是 gofmt 格式

Go 的样板代码很多,而且 \`gofmt\` 会把每个 \`if\` 展开成三行、把结构体声明拆成多行。
要在 100 行内实现完整功能,只能采用和 \`python/mvp_agent.py\` 同样的**紧凑排版**
(用 \`;\` 把多个语句写在同一行)。这是为行数硬约束做的刻意取舍:

- \`go build\` 通过,\`go vet\` 干净,\`go test\` 全绿;
- 但 \`gofmt -l .\` 会列出该文件——**这是预期行为**,不要直接 \`gofmt -w\`,
  否则行数会显著超出 100。

## 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| \`LLM_API_KEY\` | (无,必填) | 也接受 \`DEEPSEEK_API_KEY\` / \`OPENAI_API_KEY\` |
| \`LLM_BASE_URL\` | \`https://api.deepseek.com/v1\` | 其他兼容后端 |
| \`LLM_MODEL\` | \`deepseek-chat\` | 模型名 |
| \`LLM_MAX_TURNS\` | \`15\` | 单轮最多工具循环次数 |
| \`LLM_TIMEOUT\` | \`120\` | 单次 API 请求超时(秒) |
| \`LLM_TOOL_TIMEOUT\` | \`60\` | 单个工具执行超时(秒) |
| \`LLM_MAX_TOOL_CHARS\` | \`16000\` | 回填给模型的单个工具结果上限(按字符) |
| \`LLM_MAX_HISTORY\` | \`40\` | 保留的最近消息条数,超出则裁剪最旧历史 |

## 内置工具

| 工具 | 参数 | 作用 |
|---|---|---|
| \`tool_bash\` | \`cmd\` | 执行系统命令(优先用 \`/bin/bash\`) |
| \`tool_read\` | \`fp\` | 读取文件(非法 UTF-8 按 U+FFFD 替换) |
| \`tool_write\` | \`fp\`, \`data\` | 写入文件(自动创建父目录) |

## 设计要点

- **对话历史始终合法**:参数解析、查表、调用工具中的任何异常都会转成一条
  \`tool\` 结果写回,保证每个 \`tool_call\` 都有配对响应(否则下一轮请求会 400)。
- **上下文有界**:超过 \`LLM_MAX_HISTORY\` 时,在**每次请求前的安全边界**裁剪最旧
  历史;裁剪点落在 \`tool\` 结果上会继续前移,绝不拆开 \`tool_calls\` 与它的响应。
- **错误分类**:工具错误标为 \`[错误]工具 … 调用失败\`,不会误报成 \`API失败\`;
  HTTP 错误保留响应体;上下文超长单独提示。
- **按字符截断**:\`[]rune\` 计数,与 Python 版一致,中文等多字节内容不会被腰斩。
- **配置显式传递**:全部参数收在 \`Cfg\` 结构体里,测试可直接替换,无需改进程环境。

## 测试

\`\`\`bash
go test ./...
go vet ./...
\`\`\`

测试全部离线:工具、裁剪、超时、管道死锁回归、历史合法性;端到端用 \`httptest\`
起本地假服务,并在**每一次请求**上断言历史合法与消息数有界。不联网、不需要真实 API Key。

## ⚠️ 安全提示

\`tool_bash\` 能以当前用户权限执行**任意命令**,\`tool_write\` 能写**任意路径**。
接入外部输入前务必考虑 prompt injection,生产环境建议加命令白名单、限制工作目录,
或在沙箱/容器中运行。
